# Changelog

All notable changes to Studio Starter. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
versions follow [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-11-21

First version.

### Added

- Section blocks for ContentBox Studio: Hero, Content with image (four layouts), Features, Pricing, Call to action;
  the theme's own Text and Heading in place of Studio's core blocks.
- Background tones per section (light, light tinted, dark, brand color).
- Design presets Bold and Editorial (theme setting), with self-hosted fonts.
- Layout with header (main menu, blog link, optional button), footer and mobile menu.
- Blog list as cards, category and search results, post view; the post header in Studio's editor.
- Theme settings: preset, language, blog heading, header button.
- Page caches are cleared when the theme settings are saved.
